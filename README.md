# AI Engineering

## Installeren

1. Installeer de packages: `uv sync`
2. Maak je eigen `.env`: `cp .env.example .env` en zet je OpenAI API key erin.

## Starten

| Les | Starten | Code |
|---|---|---|
| 1. Je eerste AI call | `uv run les1` | `src/ai_engineering/ai_call.py` |
| 2. Memory | `uv run les2` | `src/ai_engineering/memory.py` |
